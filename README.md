📊SALES DASHBOARD PROJECT

📌 OVERVIEW

This project presents an interactive sales dashboard built using Microsoft Excel to analyze business performance across regions, categories, and customers.

The dashboard helps in identifying key trends, tracking KPIs, and generating actionable business insights.

🎯 OBJECTIVES:

Track key performance Indicators (KPIs)
Analyze sales across different regions and categories
Identify top-performing customers
Provide insights for better decision-making

🛠 TOOLS & SKILLS USED:

Microsoft Excel
Pivot Tables
Slicers (Filters)
Data Visualization
KPI Metrics

📂 DATASETS:

The dataset includes:

Order ID
Sales
Profit
Region
Category
Customer Name

✔ Data was cleaned and processed before analysis.

📊 DASHBOARD FEATURES:

KPI Cards (Total Sales, Profit, Orders, Avg Sales)
Sales by Region
Sales by Category
Monthly Sales Trend
Top 10 Customers
Interactive Slicers (Region, Segment, Category)

🔍 KEY INSIGHTS:

Profit margin is low compared to total sales
Sales are concentrated in a single category
A few customers contribute a major portion of revenue
West region outperforms other regions

📈 CONCLUSION:

The dashboard provides a clear overview of business performance and highlights key areas for improvement, such as increasing profitability and reducing dependency on specific categories and customers.
